# Card Catalog — трекер задач

Портфолио-проект: FastAPI-бэкенд + фронтенд без фреймворков, один
процесс отдаёт и API, и интерфейс. Деловой чёрно-бежевый стиль,
тёмная/светлая тема, переключение RU/EN, сортировка по дедлайну,
кастомные SVG-иконки — без внешних библиотек иконок.

## Что внутри

- **FastAPI + SQLAlchemy**, слоистая структура (models/schemas/crud/routers)
- **Дедлайн у задачи** — открытые задачи автоматически сортируются
  по ближайшей дате, просроченные подсвечиваются
- **Инлайн-редактирование** — клик по заголовку карточки превращает
  его в поле ввода
- **Круглый чекбокс** вместо кнопки "Закрыть" — клик зачёркивает
  задачу и плавно переносит её в раздел "Закрыто"
- **Тёмная/светлая тема** и **RU/EN** — оба выбора сохраняются в
  localStorage браузера
- **Кастомные иконки** для категорий, чекбокса и удаления — простые
  inline SVG, ничего не подгружается с внешних CDN

Сознательно убрал поле приоритета и заметки, которые были в прошлой
версии, но нигде не использовались по-настоящему — меньше кода,
меньше визуального шума.

## Структура

## Запуск

```
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открой **http://localhost:8000**.

## Деплой (бесплатно, без карты) — Render

1. Залей на GitHub
2. render.com → New → Web Service → подключи репозиторий
3. Root Directory: `backend`
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
6. Instance Type: **Free**

Бесплатный тариф засыпает после 15 минут простоя — первое открытие
после паузы грузится 20-30 секунд, дальше быстро. Для портфолио это
не проблема.

## Идеи для дальнейшего развития (если захочешь впечатлить сильнее)

- **Drag-and-drop** между категориями или для ручной сортировки внутри списка
- **Экспорт в CSV/JSON** — кнопка "скачать мои задачи"
- **Клавиатурные шорткаты** — например `N` для новой задачи, `/` для фокуса на поиск
- **Общий доступ по ссылке** — публичная read-only ссылка на конкретную картотеку
- **Мини-календарь** сверху, показывающий дни с дедлайнами точками
- **История изменений** задачи (когда создана, когда закрыта, сколько провисела)

Любую из них можно добавить отдельным шагом, не переписывая всё
остальное — структура для этого достаточно чистая.
