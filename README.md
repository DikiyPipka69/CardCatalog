# CARD CATALOG

**Минималистичный трекер задач на FastAPI без frontend-фреймворков**

---

## О проекте

**Card Catalog** — небольшой full-stack проект в стиле цифровой картотеки.

Приложение позволяет создавать задачи, назначать им категорию и дедлайн, редактировать их прямо в карточке и закрывать одним нажатием.

Frontend и API работают в **одном FastAPI-процессе** — без React, Vue и других frontend-фреймворков.

Главная идея проекта — сделать обычный task tracker **простым визуально и аккуратным технически**.

---

## Возможности

### 📋 Работа с задачами

* создание новой задачи;
* название, категория и дедлайн;
* редактирование названия прямо в карточке;
* удаление задачи;
* закрытие задачи круглым чекбоксом;
* автоматическое перемещение закрытых задач в отдельный раздел.

### 📅 Дедлайны

Открытые задачи автоматически сортируются по ближайшему дедлайну.

Просроченные задачи визуально выделяются, поэтому не нужно отдельно искать, что уже требует внимания.

### 🎨 Интерфейс

* тёмная и светлая темы;
* переключение **RU / EN**;
* оба предпочтения сохраняются в `localStorage`;
* адаптивная вёрстка;
* собственные SVG-иконки без сторонних icon-библиотек и CDN.

### 🧹 Минималистичная модель

В проекте сознательно нет приоритетов, заметок и других полей, которые не используются в основном сценарии.

Меньше сущностей → меньше логики → чище интерфейс.


Backend разделён на отдельные слои:

`models` → структура данных
`schemas` → валидация
`crud` → работа с БД
`routers` → HTTP API

## Запуск

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

После запуска:

**http://localhost:8000**

---

## Деплой

Проект можно бесплатно разместить на **Render**.

```text
Root Directory
backend

Build Command
pip install -r requirements.txt

Start Command
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

Для портфолио этого достаточно: приложение работает как единый Web Service без отдельного frontend-хостинга.
